## Task 1

## Objective

To compile a simple C program of sum 1 to n numbers using both GCC and RISC-V GCC compilers.
To understand the compilation flow and analyze the generated RISC-V assembly instructions.

## Task 2

## Objective

To execute and debug a RISC-V compiled C program using the SPIKE simulator.
To compare the effects of **-O1** and **-Ofast** optimization levels on the generated code.

## Task 3

## Objective

For validation of RISC-V Development Environment using GitHub Codespaces.
For execution of RISC-V Reference Program and analysis of software to hardware execution process.
For analysis of VSDFPGA Lab structure, Memory, Memory Mapped IOs, and concepts of FPGA IP.

## Task 4

## Objective

Designing and incorporating a customized memory-mapped GPIO IP core into the current RISC-V SoC.
Understanding the peripheral address decoding, reading/writing process, and communication between CPU and peripherals using memory-mapped I/O.
Testing the operation of GPIOs via write/read back processes using firmware and iverilog simulations.

## Task 5
## Objective

To develop a customized SPI Master IP for the VSDSquadron RISC-V SoC through memory mapping.
To learn about the SPI communication interface that involves clock generation, data shifting in serial fashion, state machine driven transfer process, and interaction with registers via software.
To incorporate the SPI peripheral within the SoC using memory mapping method and test its functionality by loopback simulation in the software.

## Task 6
## Objective

To validate the functionality of the SPI Master IP through a combination of software and hardware verification.
To develop firmware code to configure the SPI peripheral, send data, monitor transfer status, and verify received data using loopback communication.
To examine the UART output, simulation waveforms, and FPGA implementation to ensure proper incorporation of the SPI Master IP within the VSDSquadron.

## Task 7
## Objective

To develop the SPI Master as a robust and professional ready-for-use IP along with the detailed documentation for the VSDSquadron FPGA family.
To design user guide documents, register maps, integration documents, example software, and validation documents to understand the RTL implementation of the IP.
To document the entire IP library in accordance with industry standard documentation guidelines.
